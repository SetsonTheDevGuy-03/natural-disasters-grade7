FILES
- index.html        Home page
- lesson.html       Complete lesson
- namibia.html      Namibia-focused content
- activities.html   Learner interaction/discussion
- quiz.html         Interactive quiz
- resources.html    Video and educational links

HOW TO USE
1. Open index.html in a browser to preview locally.
2. Upload the entire folder to any static host (GitHub Pages, Cloudflare Pages, Netlify, Hostinger, etc.).
3. Make sure all files remain in the same folder.
4. Confirm Tuyenikelao N. Neshuku's programme and study mode before final submission.
5. After publishing, take screenshots of the Home, Lesson, Resources, Activities and Quiz pages for the assignment PDF.

No WordPress or CMS is required by the assignment as long as the website is publicly accessible through a working URL.
